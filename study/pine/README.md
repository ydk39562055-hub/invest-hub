# ICT 인트라데이 Pine 스크립트 (1분 · 5분 · 15분)

트레이딩뷰 Pine v6. 세 스크립트를 함께 쓰도록 설계했고, 히든 플롯으로 서로 연동된다.

| 파일 | 역할 | 패널 |
|---|---|---|
| `ict_sweep_mss.pine` | 유동성 레벨 · 스윕 감지 · 변위 MSS · 셋업 점수 | 차트 위 |
| `ict_anchored_vwap.pine` | 스윕 캔들 앵커드 VWAP · σ 밴드 · 재탈환/무효화 | 차트 위 |
| `ict_cvd_delta.pine` | 봉별 델타 · 세션 CVD 캔들 · 흡수 · 가격-CVD 다이버전스 | 별도 패널 |

## 설치

1. 트레이딩뷰 하단 **Pine 편집기** 열기 → 새 스크립트 → 파일 내용 전체 붙여넣기 → **차트에 추가**.
2. 세 파일 모두 같은 순서로 반복. 이름은 `ICT MSS`, `ICT AVWAP`, `ICT CVD` 로 뜬다.
3. **연동 설정**: `ICT AVWAP` 설정 → "연동: 스윕 신호 소스" 드롭다운에서 `ICT MSS: ▸ Sweep Signal` 선택.
   `ICT MSS` 가 차트에 먼저 올라가 있어야 드롭다운에 나온다. 소스를 안 고르면 추가할 때 클릭한 봉에
   수동 앵커로 동작하고, 오른쪽 아래 상태 테이블에 "소스 미선택" 안내가 뜬다.
   연동 후에도 표시 구간 안에 외부 스윕이 한 번도 없으면 VWAP 이 안 그려진다. 그때는 "외부 유동성 스윕만 앵커" 를 끄거나 차트를 뒤로 넘겨 본다.
4. `ICT CVD` 는 두 번 추가해서 하나는 표시 "CVD", 하나는 "델타" 로 두면 스케일 문제가 없다.

## 1분봉에서 되는가

| 도구 | 1분 | 조건 |
|---|---|---|
| MSS + 스윕 | 됨 | 스윙 길이 자동(3). 셋업은 **외부 유동성**(PDH/PDL, 세션 고저, 15분 스윙) 스윕 뒤에만 인정. 1분 내부 스윙 스윕은 점수 1점짜리 |
| 앵커드 VWAP | 됨 | 제약 없음. 재탈환 연속 종가 수를 3으로 |
| 델타 / CVD | 조건부 | 진짜 델타는 **초봉(1S) 데이터**가 필요 → Premium 이상에서 "초봉 사용" 켜기. 그 외 플랜은 1분 봉 하나를 종가 위치로 나눈 근사값이고 테이블에 ⚠ 가 뜬다 |

초봉 없이 1분 차트에서 델타를 읽어야 하면, 델타 판단은 5분 차트에서 하고 진입만 1분에서 하는 쪽이 맞다.
하위 봉 총량 제한(100,000개) 때문에 1분 + 1S 조합은 과거 약 1,600봉만 계산된다.

## 타임프레임별 권장 설정

| 항목 | 1분 | 5분 | 15분 |
|---|---|---|---|
| 차트 스윙 피벗 길이 | 3 (자동) | 3 (자동) | 5 (자동) |
| HTF 스윙 타임프레임 | 15 | 15 또는 60 | 60 |
| 변위 배수 | 지수선물 1.5 · 주식 2.0 | 동일 | 동일 |
| 스윕 후 MSS 허용 봉 수 | 20~30 | 12~20 | 8~12 |
| AVWAP 재탈환 연속 종가 | 3 | 2 | 1~2 |
| CVD 하위 TF | 1S (Premium) / 자체 근사 | 1 | 1 |
| CVD 피벗 길이 | 3 (자동) | 3 (자동) | 5 (자동) |

## 셋업 점수 (ICT MSS)

| 항목 | 점수 |
|---|---|
| 외부 유동성 스윕 (PDH/PDL · 세션 · HTF 스윙) | 2 |
| 내부 스윙 스윕 | 1 |
| 킬존 안에서 MSS | 1 |
| 스윕 레벨이 HTF 레인지의 프리미엄(숏) / 디스카운트(롱) | 1 |
| 강한 변위 (배수 × 1.5 이상) | 1 |
| SMT (상관 자산이 같은 레벨 돌파 실패) | 1 (옵션) |

기본 최소 점수 3. 외부 스윕 + 킬존만으로도 3점이라 1분봉에서는 4로 올리는 걸 권한다.

## 실전 순서

1. `ICT MSS` 에서 주황 라벨(외부 스윕)이 뜬다. 킬존 배경 밖이면 무시.
2. `ICT CVD` 에서 같은 봉이 노란 배경(큰 델타)이고 다이아몬드(흡수)가 찍혔는지 본다.
3. 반대 방향 삼각형(MSS)과 FVG 박스가 나오면 `ICT AVWAP` 이 자동으로 스윕 캔들에 앵커된다.
4. 가격이 FVG 박스로 되돌아오면서 AVWAP 위(롱) 또는 아래(숏)를 유지하고 RECLAIM 라벨이 뜨면 진입.
5. FAIL 라벨(스윕 극단값 종가 이탈)이 뜨면 셋업 폐기.

## 한국 주식 설정

- 타임존 `Asia/Seoul`
- 아시아 세션을 `0900-1000` 으로 바꿔 시초 레인지로 사용, 런던/뉴욕 세션은 끄기
- 킬존 1 `0900-1000`, 킬존 2 `1400-1520`, 킬존 3 은 아무 값이나 두고 무시
- SMT 상관 자산: KOSPI200 선물(`KRX:K200F` 계열) 또는 동종 대장주

## 알려진 한계

- 피벗 방식이라 스윙은 길이만큼 늦게 확정된다. 방금 만든 고점이 바로 깨지는 경우는 못 잡는다.
- HTF 스윙은 1봉 지연 확정으로 리페인트를 막았다. 대신 HTF 봉이 닫힌 뒤에야 레벨이 갱신된다.
- 델타는 어떤 플랜이든 체결 방향의 근사값이다. 실제 체결 방향은 Premium 의 Volume Footprint 에서만 볼 수 있다.
- 지연 데이터(실시간 구독 없는 CME 선물, 미국 주식)에서는 인트라데이 델타가 의미 없다.
- 이 스크립트들은 트레이딩뷰 편집기에서 직접 컴파일해 보지 못했다. 컴파일 오류가 나면 오류 문구를 그대로 전달하면 고친다.
